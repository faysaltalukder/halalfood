Courier & COD desk

Test the server-side connections first. Each real booking requires an explicit admin confirmation.

Pathao also needs PATHAO_USERNAME, PATHAO_PASSWORD and PATHAO_STORE_ID in Supabase Secrets, in addition to Client ID and Client Secret. REDX needs REDX_API_TOKEN and REDX_PICKUP_STORE_ID; use the area lookup in the parcel form to save the exact destination area. REDX defaults to the sandbox API for safe testing. Leave REDX_BASE_URL unset for now; only set it to the production host when you are ready for actual delivery bookings. If the token is rejected by sandbox, confirm sandbox/API access with REDX before switching environments. Connection tests and area lookups do not create shipments. A successful Steadfast balance/API test does not guarantee create-order activation: if booking returns HTTP 401 “Account is not active!”, ask Steadfast to activate API booking before retrying.
