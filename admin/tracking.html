How the controls work

Server controls are checked per event, and the same event ID is shared by the browser Pixel and server integration when CAPI is enabled.

  • Meta Pixel: controls browser-side event collection.
  • Meta CAPI: controls server-side delivery. Event names and event IDs are checked before dispatch, and delivery outcomes are logged privately.
  • GA4: controls event commands sent to the existing Google/GTM setup.
  • Purchase: remains blocked by a server-side guard until live commerce is explicitly enabled.
