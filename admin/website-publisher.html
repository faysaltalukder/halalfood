AI AGENT HANDOFF

Draft-only workflow

Copy the instructions for an agent that has Supabase access but no GitHub access.

  1. Use the server function action source_read to read current text files and capture the returned headSha.
  2. Insert one site_change_sets row with status='draft' and that exact base_commit_sha.
  3. Insert one site_change_files row per changed path. For add/modify, include the complete file content; for delete, set content = null.
  4. Give the change-set ID to the admin. Do not set approval fields, publish status, or credentials.

Binary images/PDFs are disabled in this first version. Publishing blocks .github/**, supabase/**, site-release.json and protected admin login/security files.
