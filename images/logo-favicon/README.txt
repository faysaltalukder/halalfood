HALAL FOOD — LOGO & FAVICON
============================

Replace these files with your own PNG images, keeping the exact filenames:

logo.png
    Main website logo. Recommended: transparent PNG.

favicon.png
    Browser favicon. Recommended: square PNG, 512x512 or larger.

apple-touch-icon.png
    Mobile/home-screen icon. Recommended: square PNG.

Important:
- Use PNG only for these editable brand assets.
- Keep the filenames unchanged.
- After replacing the files, the website will use them automatically.
